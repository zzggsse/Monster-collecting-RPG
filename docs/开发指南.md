# 荒野精灵 · 开发指南

面向想改玩法、加内容、替换美术的开发者。所有逻辑都在 `core/`，改动后 `gradlew.bat build` 即可重新编译，无需额外配置。

## 1. 模块总览

| 模块 | 路径 | 职责 |
| --- | --- | --- |
| 模型 | `core/.../model/` | 精灵、技能、图鉴、地图、状态、对话等纯数据与规则 |
| 界面 | `core/.../screen/` | `TitleScreen` 主菜单 / `ExplorationScreen` 探索 / `BattleScreen` 战斗 |
| 图形 | `core/.../gfx/Assets.java` | 瓦片贴图、精灵图标、中文字体 |
| 音频 | `core/.../audio/AudioEngine.java` | 程序生成 WAV 音效与三区域主题曲 |
| 入口 | `core/.../WildSpiritGame.java` | 存档、区域切换、战斗结束回调、测试钩子 |
| 启动器 | `lwjgl3/` | 桌面窗口与 `main` 入口 |

## 2. 地图编辑（Regions.java）

三张地图用字符网格定义（20 列，不足自动补 `#`），直接在 `core/.../model/Regions.java` 的字符串数组里改：

| 字符 | 含义 | 备注 |
| --- | --- | --- |
| `#` | 墙体 / 障碍 | 不可走 |
| `~` | 水面 | 不可走 |
| `.` | 草丛 | 可走，随机遭遇野生精灵 |
| `;` | 小路 | 可走，不遇敌 |
| `P` | 玩家出生点 | 每图 1 个 |
| `E` | 出口 / 传送门 | 站上去按空格 |
| `B` | 区域头目 | 踩到触发头目战 |
| `F` | 树果 | 拾取 +1 回复药，可被 `GameState.collected` 记录 |
| `H` | 治疗师 | 全队回满 HP 与 PP、清除状态 |
| `n` | NPC | 踩到触发对话，内容见 `model/Dialogues.java` |

新地图 = 新增一个 `Region` 常量并加入 `Regions.all()`；区域有 `wildPool` / `boss` / `bossBadge` 关联（见 `Dex.regionBoss`）。

## 3. 添加精灵（加一行）

1. 在 `model/Dex.java` 增加种族定义，例如：
   ```java
   public static final Species XXX = sp("xxx", "名字", Types.草, 50, 20, 18, 15, "forest",
           new Move[]{C_TENGBIAN, C_FEIYEDAO});
   ```
   - `key`：唯一英文标识；`region`：`all`（通用）/ `forest` / `desert` / `snow` / `none`（不野外出现，如初始精灵与进化型）
   - 进化链：`XXX.setEvolution(YYY, 14);`（Lv14 进化成 YYY）
2. 在静态块里登记：`ALL.put(XXX.key, XXX);`
3. 图标：放 64×64 PNG 到 `assets/sprites/`，并在 `gfx/Assets.java` 的 `SPRITE` 映射加一行：`SPRITE.put("xxx", "文件名");`
   - 没有新图标也能玩：会显示默认占位圆点，建议尽快补图
4. 数值平衡参考：野生等级 `wildMaxLevel = 6 + 区域序号*7`，头目 `bossLevel = 9 + 区域序号*7`

## 4. 添加技能（带状态）

`Dex.java` 中：

```java
public static final Move C_DUFEN = mv("毒粉", Types.GRASS, 14, Status.POISON, 0.4f);
```

- 参数：名称、属性、威力、状态（无则 `Status.NONE`）、触发几率（0~1）
- 每个技能的最大次数在 `Dex.PP` 表登记（`PP.put("毒粉", 30);`），缺省 20
- 状态效果定义在 `model/Status.java`：`dotFrac` 控制每回合掉血比例；`immuneTo(Types)` 定义属性免疫
- 敌人 AI：当敌方有状态技且我方未中状态时，50% 概率先放状态

## 5. 存档格式（save.txt）

位于 `%USERPROFILE%\WildSpirit\save.txt`，按行存储（`GameState.saveTo/loadFrom`）：

```text
v1
0                       # 区域索引
1                       # 玩家 X
1                       # 玩家 Y
0                       # 当前精灵下标
badges:forestBoss       # 已获徽章
potions:5               # 回复药数量
collected:0:6,1:8,2     # 已拾取树果
seen:...                # 已见
caught:starter=1        # 捕获计数
creature:starter|焰苗|7|80|120|pp:26,35,0,0|st:BURN   # 队伍精灵
```

- 旧版本存档缺少新字段时自动补默认值，向后兼容
- 教学：任何 `creature:` 行 = `种族key|名字|等级|当前HP|经验|pp:各技能剩余PP|st:状态英文名`

## 6. 中文字体管线（不会缺字）

`core/build.gradle` 的 `collectCjk` 任务在构建时自动扫描 Java 源码，收集出现的汉字 + 常用符号到 `core/build/generated-i18n/i18n.txt`，字体加载时并入字符集：
- 新增任何中文字符串后**重新构建**即自动收录，不用手改字体
- 字体文件：`assets/fonts/simhei.ttf`（可由其他中文字体替换，保持同名）

## 7. 音效与音乐

`audio/AudioEngine.java` 用纯代码合成 WAV（方波芯片音），写入系统临时目录后由 LibGDX 播放：
- 接口：`select / hit / hurt / capture / levelup / itemPickup / heal / encounter / escape / win / lose`
- 主题：`playRegionTheme("forest"|"desert"|"snow")`
- 想关音乐可把 `playRegionTheme` 里的 `vol` 调到 0，或后续接入设置菜单

## 8. 自动化测试钩子（已内置）

无需改代码即可做回归冒烟测试，环境变量在启动前设置：

| 变量 | 作用 |
| --- | --- |
| `WILDRUN_SECONDS=8` | 8 秒后自动退出（CI 冒烟测试） |
| `WILDRUN_AUTO=1` | 跳过标题直接开新档进入探索 |
| `WILDRUN_SHOT_SECONDS=3` | 3 秒后自动截图到 `%USERPROFILE%\WildSpirit\screenshot.png` |

配合方式：`WILDRUN_AUTO=1 WILDRUN_SHOT_SECONDS=3 WILDRUN_SECONDS=8 gradlew.bat lwjgl3:run`，退出码 0 即为通过。

## 9. 常用构建命令

```bash
gradlew.bat build           # 完整构建（含字库收集）
gradlew.bat lwjgl3:run      # 运行游戏
```

- 本地已有 `D:\game\tools\gradle-8.10.2` 时，`run-game.bat` 直接用它；否则自动走 wrapper
- 代码风格：4 空格缩进、无分号省略、注释用中文
